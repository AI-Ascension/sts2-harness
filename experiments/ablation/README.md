# Safety and information ablation plan

The ablation runner compares bounded cohorts while preserving build and configuration lineage. It
does not infer hidden outcomes and does not turn a single trajectory into a performance claim.

Required factors are removal or masking of visible fields, bounded provider delay, stale catalogs,
corrupted envelopes, and confidence degradation. Each cell reports legality, stale rejection,
verification, recovery, regret, calibration, resource use, progression, and victory/defeat
separately. Unknown or unavailable cells remain unknown; they are not scored as failures or wins.

Run only against synthetic or explicitly authorized disposable episodes. Do not retain raw prompts,
verbatim model output, screenshots, saves, credentials, or host dumps.
