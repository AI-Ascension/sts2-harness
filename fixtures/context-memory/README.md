# Phase 3 synthetic memory fixtures

These small original fixtures exercise visible history, late admission, future outcomes,
branch-sibling and private scopes, protected facts, revocation and expiry. They are consumed by
the independent tests in `crates/harness/tests/phase3_memory.rs`; expected eligibility is written
by the test author rather than calculated by the corpus implementation. The text is synthetic and
contains no provider credentials, hidden reasoning, game saves or proprietary assets.

`source-registry.json` is metadata. The `path` values are repository fixture labels only; runtime
callers resolve approved opaque content identities and never accept arbitrary filesystem paths.
