# CV watchdog validation

Status: proposed and unverified on 2026-09-04.

The watchdog contract is limited to an independently derived disagreement signal. It cannot write
game input, choose an action, replace the host-generated catalog, expose hidden state, or resolve a
semantic contradiction. The planned validation uses synthetic fixtures only and records detector
revision, fixture digest, threshold, platform, output digest, and retention decision.

No provider, screenshot capture, game process, valued save, or live visual model was available for
this workspace. Therefore this document makes no claim about detector accuracy or target-build
compatibility.
