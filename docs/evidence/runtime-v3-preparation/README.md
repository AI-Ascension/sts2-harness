# Runtime-v3 preparation evidence

This directory owns hand-authored Runtime-v3 fair-play field classifications and quarantined
patch-release preparation. It is not the expert-state research baseline, a generated state
inventory, or evidence of observed target-game behavior.

- [Observation fields](data/observations.json) classify admitted projection fields.
- [Action fields](data/actions.json) distinguish host authority from provider selection.
- [Information importance](data/information-importance.csv) records bounded source-derived priors.
- [Claim evidence](data/claim-evidence-matrix.csv) separates available tests from missing evidence.
- [Build manifest](data/build-manifest.json) uses `sts2-patch-manifest-v1` and remains quarantined.

These five files originally collided with different files proposed by research PR #9 under
`docs/research/sts2-expert-state-package/data/`. The preparation namespace keeps the two sets
independent: the research proposal has state/action/observation join tables and a research
provenance manifest, not this runtime field-classification format or patch manifest. Neither
package can substitute for the other. Research and runtime proposals are not Git ancestors.

CSV `data/` evidence paths are relative to this directory; `crates/` paths are repository-relative.
No state counts, observations, host traces, or protocol contracts were generated by this move.
CI still requires all five preparation files and validates the quarantined patch manifest.
