## Replay investigation

because observation timing assigned different IDs to identical public hand/exhaust cards.
The current native combat, player content, and card fields matched the recorded boundary;
the autogenerated exhausted card had been observed before the hand in one invocation.
This failed replay remains preserved and is not a complete replay pass.

[ADR 0009](../decisions/0009-seeded-episode-replay.md) now defines conservative one-to-one
card rebinding with ordered pile/content comparison, retained lineage, duplicate ambiguity
rejection, and unique current legal payload matching. The full workspace tests, Clippy,
formatting, and strict policy pass. These are source checks, not native replay completion.

A second fresh replay passed that boundary and settled 392 actions. It then stopped before
a card selection because that native choice appended a display label to the rebound identity.
No mutation remained unresolved. This attempt is also preserved as incomplete. Rebinding now
handles the established base plus one exact sanitized label; changed labels, unknown bases,
and arbitrary prefixes are not normalized away. Focused selection-dispatch tests and all
workspace checks pass.
